# Challenge: Fix the broken cart

**Time:** about 30 min

The starter prints a cart summary, but it has **5 bugs**: some crash, some just print the wrong thing. Find and fix them all using the Console, breakpoints and the debugging process from this module. Write a comment above each fix saying what was wrong.

When it's fixed, it prints exactly this:

```text
2 × T-shirt: $50.00
1 × Backpack: $45.00
Subtotal: $95.00
Discount (SAVE10): $9.50
Delivery: $15.00
Total: $100.50
```

**What you should see in the Console:**

```text
2 × T-shirt: $50.00
1 × Backpack: $45.00
Subtotal: $95.00
Discount (SAVE10): $9.50
Delivery: $15.00
Total: $100.50
```
