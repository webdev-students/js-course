# Challenge: To-do list

**Time:** about 45 min

Build a to-do list:

1. A form with a text box and an **Add** button. Submitting adds the to-do to the list — but not if it's empty (show `Please type a to-do.` under the box and focus it).
2. Each to-do has a checkbox (tick = done, crossed out) and a **Delete** button.
3. Use **one** click listener on the list (event delegation) and `data-action` attributes.
4. Show `2 left` (or `1 left`, `0 left`) under the list.
