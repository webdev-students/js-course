# The JavaScript course — starter files

Welcome! This repo has everything you need to follow along with the videos.

## Getting started

1. Clone (or download) this repo.
2. Open it in **VS Code**.
3. Install the **Live Server** extension, if you haven't already (lesson 1.3 shows you how).

## How it's organised

Each module has its own folder, and each lesson has its own folder inside it:

```
7-arrays/
  7.1-array-basics-and-indexes/   ← the files the lesson starts with
    slides/                       ← the slides from the video
  7.2-push-pop-shift-unshift/
  …
  exercises/                      ← practice tasks (README.md) + a starter folder for each
  assignment/                     ← BRIEF.md + the starter files for the module project
  QUIZ.md                         ← check what you've learned
```

## For every lesson

1. Open the lesson's folder.
2. Right-click `index.html` → **Open with Live Server** (or open the Console, if the lesson says so).
3. Type along with the video. Don't copy and paste. Typing it yourself is how it sticks.
4. Stuck? Re-watch the last step slowly, and read the error message. That's a skill we practise all course long.

## Exercises, assignments and quizzes

- **Exercises:** at the end of each module, `exercises/README.md` lists the tasks, easy to hard. Each one has a starter folder.
- **Assignment:** one bigger project per module. Read `assignment/BRIEF.md`, build it in `assignment/`, then watch the solution video.
- **Quiz:** `QUIZ.md` is 8–10 quick questions to check your understanding.

## The capstone: our Checkout store

In Module 15 you build a complete online store, in a **new, empty folder of your own**, one step at a time. The slides for each step are in `15-capstone/slides/`.

> There's no real backend and no real payment in the store: products come from a free practice API, and your cart and orders are saved in your own browser.

Have fun, and happy coding!
