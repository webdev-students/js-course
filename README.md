# The JavaScript course — starter files

Welcome! This repo has everything you need to follow along with the videos.

## Getting started

1. Clone (or download) this repo.
2. Open it in **VS Code**.
3. Install the **Live Server** extension, if you haven't already (lesson 1.2 shows you how).

## How it's organised

Each module has its own folder, and each video has its own folder inside it:

```
7-arrays/
  7.1-arrays-basics/        ← the files the video starts with
    slides/                 ← the slides from the video
  7.2-searching-arrays/
  …
  challenge/                ← one challenge per module: README.md + starter files
```

## For every video

1. Open the video's folder.
2. Right-click `index.html` → **Open with Live Server**, and open the Console.
3. Type along with the video. Typing it yourself is how it sticks.
4. Stuck? Re-watch the last bit slowly, and read the error message. That's a skill we practise all course long.

## Challenges

At the end of every module there's **one challenge**. Read `challenge/README.md`, build it in that folder, and give it a real try before you look anything up.

## The capstone: our Checkout store

In Module 15 you build a complete online store, in a **new, empty folder of your own**. The slides for each part are in `15-capstone/slides/`.

> There's no real backend and no real payment in the store: products come from a free practice API, and your cart and orders are saved in your own browser.

Have fun, and happy coding!
