# Challenge: Hello, Console

**Time:** about 15 min

Set up your own little script and use the Console as a calculator.

1. Open the `challenge/starter/` folder in VS Code and start Live Server.
2. In `script.js`, print three lines about yourself, each with a label — like `Name: John Doe`.
3. A shop sells **T-shirts for $25**, **caps for $15** and **socks for $5**. Print, each with a label:
   - the cost of **3 T-shirts**,
   - the cost of **one of each**,
   - the **change from $100** after buying one of each (use brackets so the adding happens first).
4. Print one warning with `console.warn`.

**What you should see in the Console:**

```text
Name: John Doe
City: London
Favourite colour: Blue
3 T-shirts: 75
One of each: 45
Change from 100: 55
⚠️ Remember to save before you check the Console!
```
