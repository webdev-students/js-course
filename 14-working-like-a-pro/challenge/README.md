# Challenge: Clean it, commit it, ship it

**Time:** about 45 min

Pick ONE project you built in an earlier challenge (the weather app or the mini shop are great choices) and make it portfolio-ready:

1. Run `npx prettier --write .` and `npx eslint .`, and fix every problem ESLint reports.
2. Find one piece of copy-pasted code or one magic number and clean it up. Test it still works.
3. `git init`, add a `.gitignore` with `node_modules/`, and commit with clear messages — at least three commits.
4. Push it to a new **public** GitHub repository and switch on **GitHub Pages**.
5. Write a `README.md`: what it is, the live link, how to run it, and what it's built with.
6. Go through the checklist: keyboard only, labels, one `h1`, phone size, a clean Console.

**Done when:** you've got a live link that works on your phone, and a README on GitHub.
